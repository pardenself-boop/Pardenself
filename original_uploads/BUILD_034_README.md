# BUILD 034 — STREET WIRETAP / DAW PROFILE BRIDGE

The standalone MIDI diagnostic now exports the same `MidiControlRouter` JSON schema used by the DAW hardware mapping engine. Learn button and encoder controls; select relative encoder mode before learning. The event log previews the resulting DAW commands. Legacy Build 033 Wiretap profiles are accepted and converted in memory; SAVE PROFILE writes the new compatible format.

This does not claim that Maschine Studio exposes MIDI ports without Native Instruments Controller Editor MIDI mode, or that a diagnostic command preview drives the DAW transport. Windows hardware testing is still required.

# v1.5 COOK UP MATRIX — real interface update

The v1.5 update replaces the plain COOK UP Tkinter window with a custom themed window featuring 22 LABBS, neon orb rings, waveform-style synthesis preview, live pad step matrix, Track City clip display, device-chain preview, and a real master-bus peak readout. This is a runnable interface, not AI-generated concept artwork. The existing sampler, LABB voices, note clips, arranger and Studio simulator are preserved.

## Important limitations
The banner artwork and waveform are visual previews, not captured audio. Device-chain slots are labeled DSP PLANNED; they do not implement those FX. Only SOUL currently affects LABB filter behavior. Physical NI Maschine Studio integration is not yet validated. This is a Tkinter Windows prototype, not a production VST/DAW.

Run START_WINDOWS.bat, then COOK UP MATRIX. Pillow is optional for the banner image. 16-bit PCM WAVs supported for sample loading.

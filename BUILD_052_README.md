# BOOM BAP TOOLBOXX Build 052 — Song Timeline WAV Bounce

Added `app/street_song_bounce.py` to schedule 32-pad sample hits at exact audio-frame positions, split rendering blocks at event boundaries, and export a stereo WAV. `SONG_DEMO_052.json` shows the supported format; replace its WAV path with your own 16-bit PCM WAV. Double-click `SONG_BOUNCE_DOUBLE_CLICK.cmd` on Windows after installing Python dependencies. This is a **JSON song-grid exporter**, not yet a full export from Track City UI; does not prove live audio, hardware MIDI, or installer operation.
